# ○×ブザー

研修・セミナー・クイズ大会で使う、正解／不正解のブザーです。
画面下の左半分が「正解（ピンポン）」、右半分が「不正解（ブー）」。
中央の玩具画像も同じ割り当てでタッチできます（左半分＝○、右半分＝×）。

- ネット接続なしで動作します（初回読み込み後はオフラインでも起動）
- ホーム画面に追加すると、アプリとして全画面で起動します
- 音を鳴らして3秒後に、○／×／拍手 のマークは自動で消えます
- 画面右上の ↻ で玩具の絵だけを180度回転できます。相手に画面を向けたまま、
  自分の側は通常どおりボタンを押せます

## 操作

| 操作 | 動作 |
| --- | --- |
| 画面左下 | ○ 正解（ピンポン） |
| 画面右下 | × 不正解（ブー） |
| 玩具画像の左半分 | ○ 正解（ピンポン） |
| 玩具画像の右半分 | × 不正解（ブー） |
| ○×ボタンの上「拍手」 | 拍手（アプローズ） |
| 画面右上の ↻ | 玩具の絵を180度回転（相手に見せる向き） |
| `1` / `O` | ○ 正解 |
| `2` / `X` | × 不正解 |
| `3` / `C` | 拍手 |
| スペース | 表裏を切り替え |
| `B` | 背景の黒／白 |

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 本体。効果音をBase64で内蔵した単一ファイル |
| `manifest.webmanifest` | ホーム画面追加・全画面起動の設定 |
| `sw.js` | オフライン動作用のキャッシュ |
| `icon-*.png` | アプリアイコン |

`index.html` は単体でも動作します。ダウンロードしてブラウザで開くだけで使えます。
公開ページからは、画面右上の「i」ボタン内の「HTMLファイルを保存」からも取得できます。

## 更新するとき

`index.html` を書き換えたら、`sw.js` の `CACHE` の値（`marubatsu-v1`）を
`marubatsu-v2` のように変更してください。変更しないと、既に開いたことのある
端末では古い内容が表示され続けます。
